# Design assets

- `kratt_animated.svg` — animated pixel-sprite Kratt mascot. States: idle blink, thinking (`.think`), hop (`.hop`, or hover on `.hopper`), asleep (`.sleep`). Respects `prefers-reduced-motion`.
- `kratt_four_colors_dark_and_light.svg` — flat Kratt colour exploration: deep red, chrome, British racing green, calm steel, on dark and light tiles.
- The Ember redesign boards live in `../.ember-preview/project/` (v1–v5 `*.dc.html` + `canvas.json`). Reference only.
