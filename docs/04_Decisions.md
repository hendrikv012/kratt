## 2026-11-03: optional online AI and subscriptions

The owner explicitly requested restoring local/online AI selection, APIs and supported subscription plans. This supersedes the earlier local-only product boundary. Keep local Ollama as the default, add direct provider transport inside the authenticated engine, and preserve file-based notes. Remote prompts require an explicit online choice. Credentials are kept outside notes/preferences in protected local storage. Use official ChatGPT public-client OAuth and Claude Code subscription authentication, without extracting another app's tokens or treating subscriptions as generic API keys. No Kratt cloud backend is introduced.


## 2026-11-03: ChatGPT host identifier format repair

OpenAI rejected the plain UUID generated by 1.4.0. Its official OSS overview requires UUID host IDs to use `urn:uuid:<UUIDv4>`. Version 1.4.1 generates that form and migrates existing UUIDs without changing their underlying value or account registrations. Valid opaque host identifiers remain unchanged. This is a compatibility correction, not a new host lifecycle.

## 2026-11-04 — Sources presentation follows the supplied A/B/C boxes

Use subject-to-source navigation with Rich, Simple and Preview boxes from the owner's HTML, plus the existing List. Store the style/open subject with other desktop preferences so source navigation returns to the same place. Reuse source membership, menus and synchronization; allow source creation to receive validated initial subjects. This changes presentation and default membership at creation, not the file format or engine. Architecture's version now reflects 1.5.0.
