# DNA replication

Before a cell divides it copies its whole genome. Replication is semi-conservative: each new double helix keeps one old strand and gets one new strand.

## Unwinding

Helicase breaks the hydrogen bonds between the base pairs at the origin of replication, opening a replication fork. Single-strand binding proteins keep the strands apart.

## Synthesis

DNA polymerase adds nucleotides only in the 5' to 3' direction. The leading strand is built in one piece. The lagging strand is built in short Okazaki fragments, which ligase joins together.

## Proofreading

Polymerase checks each base it adds and removes mismatches, so the error rate is about one in a billion bases.
